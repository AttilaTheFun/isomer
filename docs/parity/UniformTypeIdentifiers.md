# UniformTypeIdentifiers

Isomer's UniformTypeIdentifiers is `UTType` as SwiftUI's pickers take it: a kind of content (`allowedContentTypes: [.image, .pdf]`), its identifier, and the MIME type and file extension a host filters by, for the common types (images, movies, audio, PDF, text, JSON, HTML, ZIP). An app imports it to name `UTType`, as on Apple platforms. On Apple platforms an app uses Apple's.

## Implemented differently

- A type is its identifier and MIME type: there is no type registry or conformance tree, so `UTType(_:)` knows the common identifiers and `UTType(mimeType:)` / `UTType(filenameExtension:)` the common MIME types and extensions, and other identifiers are dynamic types with no MIME type.
