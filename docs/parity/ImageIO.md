# ImageIO

Isomer's ImageIO is the part of Apple's an app uses to decode a picture off the main thread at the size it is drawn: `CGImageSourceCreateWithData`, the source's properties (pixel size, orientation) and `CGImageSourceCreateThumbnailAtIndex`, on wasm and Android (shared/image_io). A `CGImage` is a handle to a bitmap the host decoded. On Apple platforms an app uses Apple's ImageIO.
