# CoreTransferable

Isomer's CoreTransferable is the `Transferable` protocol as SwiftUI's pickers and drops take it: a type whose values a picker or a drop hands over, `Data` (the bytes) and `URL` (where they are), with `String`. Isomer's SwiftUI re-exports it, as Apple's does. On Apple platforms an app uses Apple's CoreTransferable.

## Implemented differently

- `Transferable` has no requirements here: the hosts hand over files, and `PhotosPickerItem.loadTransferable(type:)` and `.dropDestination(for:)` read them as `Data` or `URL`. A type of an app's own (with its `transferRepresentation`) is not loaded through it yet.

## Excluded

### NSItemProvider (2)

Why: `NSItemProvider` is an Objective-C class of Foundation's (drag and drop, sharing on Apple platforms); Isomer's Foundation has no Objective-C classes.
