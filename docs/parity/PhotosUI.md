# PhotosUI

Isomer's PhotosUI is the SwiftUI photo picker: `.photosPicker(isPresented:selection:…)` asks the host's own picker (a file input on the web, the system photo picker on Android) for photos and videos, which come back as `PhotosPickerItem`s whose bytes `loadTransferable(type:)` reads as `Data` or a `URL`, with `PHPickerFilter` saying which kinds. It is compiled over each platform's SwiftUI. On Apple platforms an app uses Apple's PhotosUI (its SwiftUI picker is the PhotosUI–SwiftUI cross-import overlay).

Generated by `tools/parity/parity.py` on 2026-10-24 from Apple's iOS 27.0 SDK and Isomer at `318c9f2f`: `frameworks/photos_ui`, compiled over each platform's SwiftUI (module `PhotosUI`).

## Implemented differently

- A picked item's identifier is the picked file's path (its name, through `itemIdentifier`), not a photo library asset's: there is no photo library.
- `selectionBehavior` and `preferredItemEncoding` are taken and left to the host's picker.
