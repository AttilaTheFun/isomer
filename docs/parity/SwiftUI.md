# SwiftUI

Isomer's SwiftUI, on wasm (the web) and Android (and Linux and Windows), is the SwiftUI app code is written against, drawn by each platform's renderer (React, Jetpack Compose, or Isomer's own GPU renderer). It covers the everyday core: stacks, lists and forms, text and images, the common controls, navigation stacks and split views, tabs, toolbars, sheets and alerts, state and environment, Observation. docs/swiftui_api_audit.md goes through the gaps area by area, with priorities. On Apple platforms an app uses Apple's SwiftUI.

Generated by `tools/parity/parity.py` on 2026-10-19 from Apple's iOS 27.0 SDK and Isomer at `8fa42f41`: `shared/swift_ui_core`, `shared/renderers` and the wasm host (module `SwiftUI`).

## Implemented differently

- Behavior the renderers cannot yet give is accepted and ignored or approximated (docs/swiftui_api_audit.md, section 5): `.transition` is accepted but not animated, springs are ease-outs, `GeometryProxy.frame(in:)` is relative to the view.
