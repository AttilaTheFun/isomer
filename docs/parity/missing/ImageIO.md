# ImageIO: what Isomer does not have yet

Every declaration of Apple's ImageIO interface (iOS 27.0 SDK) that Isomer's ImageIO lacks, with Apple's signature: the list to choose what to implement next from. [ImageIO.md](../ImageIO.md) has the counts, the reasons and what is implemented differently. Generated by `tools/parity/parity.py` on 2026-10-23 with Isomer at `0a142780`.

Areas are ordered planned, then maybe, then the rest, larger first; within an area, types with the most missing first. "The type too" marks a type Isomer does not declare at all; elsewhere the type is there and these members are not. A version is the iOS release that introduced the declaration.
