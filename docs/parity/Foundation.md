# Foundation

Isomer's Foundation, on the platforms that have no Foundation of Apple's, is swift-foundation's FoundationEssentials built from Isomer's fork (AttilaTheFun/swift-foundation, branch `isomer`, from the swift-6.3.2-RELEASE tag), with the Swift value types and API Swift code uses most: `Data`, `Date`, `URL`, `UUID`, `Decimal`, `AttributedString`, JSON and property-list coding, `Calendar` basics, `FileManager`, `ProcessInfo`, `Predicate`. The fork adds what Apple's framework and swift-corelibs-foundation give Swift code through Objective-C: `CharacterSet`, the `String` methods that come from `NSString` (searching, replacing, trimming, comparing, percent encoding) and `String(format:)`. Isomer's own module adds `Bundle`, `Stream`, English calendar symbols, and `URLSession` with its requests, responses, errors and WebSocket tasks, over transports the platform's host installs. There is no swift-corelibs-foundation layer: no `NS` classes, CoreFoundation, FoundationNetworking or FoundationXML. On Apple platforms an app uses Apple's Foundation.

## Implemented differently

- `Bundle`, `InputStream` and `OutputStream` are Swift classes, not `NSObject` subclasses. A bundle is a directory found on the file system (`ISOMER_BUNDLE_PATH`, else the executable's directory); it reads no Info.plist and no strings tables (`localizedString` returns the value or the key), and `Bundle(for:)` is the main bundle. Streams read and write memory and files synchronously, with no run loop or delegate events.
- Without `--@isomer//foundation:internationalization`, `Calendar`'s symbol lists (`shortWeekdaySymbols`, `monthSymbols`, `amSymbol`…) are English whatever the calendar's locale; with it they are ICU's.
- The "localized" string comparisons (`localizedCompare`, `localizedStandardCompare`, `localizedCaseInsensitiveContains`…) compare without locale data. `String(format:)` does not apply a locale.
- `CharacterSet` equality between sets that are not explicit ranges compares every code point (slow, rare), and its hash reads only the ASCII and Latin-1 range.
- Formatting and parsing, locales, calendars beyond the Gregorian and time zones beyond GMT (FoundationInternationalization, over ICU) are an app's choice: counted here as present, they are there when the app builds with `--@isomer//foundation:internationalization`. ICU's data then comes with the app; `isomer_web_app(icu_locales = ["en", …])` keeps only the languages it names (34 MB of data becomes 6 to 7 MB for one to five languages).
- What corelibs adds to swift-foundation and apps reach for, written in Swift over swift-foundation and the C library: `NSRange` and its functions, `NSLock`, `NSRecursiveLock`, `NSCondition`, `Thread` (pthreads; in WebAssembly without threads there is one thread and starting another stops the program), `FileHandle` (reading, writing, seeking; not the run-loop background reads), `NSNumber` (not bridged: `intValue`, not `as? Int`), `NSRegularExpression` and `NSTextCheckingResult` (over Swift's `Regex`, matching by Unicode scalar with UTF-16 ranges; patterns in the syntax both read), `NSTemporaryDirectory()` and `NSHomeDirectory()`. They are Swift classes, not NSObject subclasses; `Thread.threadDictionary` is a Swift dictionary.
- `URLSession` sends http and https requests through the HTTP transport the platform's host installs in IsomerFoundation (`IsomerNetwork.http`: the browser's `fetch`, Android's HTTP stack, Apple's URLSession under WasmKit) and opens WebSockets through its WebSocket transport; without one a task fails with `URLError.notConnectedToInternet`. `file:` and `data:` URLs are read without a transport. A body is sent and received whole; the host's stack keeps its own cookies and cache and follows redirects. Completion handlers run on a task of their own, not on a delegate queue. `suspend()` keeps a task that has not started from starting; one already loading goes on. Configuration and request properties that steer Apple's network stack (cellular, expensive and constrained access, service types, connections per host, waiting for connectivity) are kept and not acted on. `URLSessionWebSocketTask.sendPing` answers once the connection is open (the transports carry no pings), and a close code `CloseCode` has no case for (an application's 4000s) reads as `.invalid`, where Apple's enum, imported from C, holds the number. `URLRequest.CachePolicy`, `NetworkServiceType` and `Attribution` are enums of `URLRequest`'s own (Apple's are typealiases of `NSURLRequest`'s); `URLResponse`, `URLSession` and its tasks and configuration are Swift classes. `Error.localizedDescription`, URLError's descriptions and `HTTPURLResponse.localizedString(forStatusCode:)` are English.
