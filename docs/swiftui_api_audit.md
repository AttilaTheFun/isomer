# SwiftUI public API coverage audit: Isomer

Date: 2026-10-11. Isomer at `main` cffc3ef (working tree as checked out). Apple SDKs: Xcode 27.0 (27A266a), iPhoneOS 27.0 and MacOSX 27.0 SDKs, `SwiftUI` + `SwiftUICore` arm64e `.swiftinterface` files (4 files, about 123k lines).

Compared by name: types by qualified name; members by container + base name + argument labels (a SwiftUI signature counts as present when Isomer can be called with the same labels, defaulted arguments and a trailing closure allowed). Argument *types* were compared only as a heuristic (section 4). Read-only audit: no code changed, no builds run. Scripts: `tools/swiftui_audit/`; raw data (regenerated by them): `/tmp/swiftui_audit/` (method in section 7).

## 1. Summary

Isomer covers the everyday core of SwiftUI well: stacks and lazy stacks/grids, `Text`/`Image`/`Label`,
`Button`/`Toggle`/`TextField`/`TextEditor`/`Picker`/`Slider`/`Stepper`, `List`/`ForEach`/`Section`/`Form`,
`NavigationStack`/`NavigationSplitView`/`NavigationLink`, `TabView`/`Tab`, toolbars, sheets, alerts,
confirmation dialogs, popovers and inspectors, `@State`/`@Binding`/`@Observable`/`@Bindable`/`@Environment`/
`@FocusState`/`@AppStorage`, `.task`/`.onChange`/`.refreshable`/`.searchable`, `ScrollViewReader`, and Liquid
Glass. Measured against the whole public surface it implements a fifth to a quarter: 154 of 716 top-level
types (only 61 with every member), 117 of 437 View-modifier base names, 10 of
117 environment values, and none of the 33 Scene modifiers.

The gaps cluster rather than scatter:

1. **Value-based navigation** (`NavigationPath`, `navigationDestination`, `NavigationLink(value:)`) is absent;
   Isomer only has destination-view links.
2. **Protocol-based customization**: no `ButtonStyle`/`LabelStyle`/`ToggleStyle`/`ProgressViewStyle`/`TextFieldStyle`
   protocols (styles are fixed option structs), no `Layout`, `PreferenceKey`, `Animatable`/`GeometryEffect`,
   `Transition`, the `@Entry` macro for environment keys, or custom `Scene` bodies.
3. **Gestures** beyond tap/drag/magnify: no `TapGesture`/`LongPressGesture` values, `onLongPressGesture`,
   `@GestureState`, `simultaneousGesture`/`highPriorityGesture`, or composition (`sequenced`, `exclusively`).
4. **Text and fonts**: no formatted text (`Text(_:format:)`, `Text(date, style:)`, `"\(x, specifier:)"`),
   no `Text(AttributedString)`, no `Font.custom`; `.fontWeight`/`.italic`/`.monospaced`/`.underline` exist only on
   `Text`, and `.kerning`/`.tracking`/`.minimumScaleFactor` not at all.
5. **Environment**: only 10 values are public (`colorScheme`, `dismiss`, `displayScale`,
   `horizontalSizeClass`, `verticalSizeClass`, `isEnabled`, `isScrollEnabled`, `refresh`, `scenePhase`,
   `defaultMinListRowHeight`); `locale`, `openURL`, `isPresented`, `isSearching`, `editMode`, `layoutDirection`,
   `dynamicTypeSize` are missing.
6. **Shapes and drawing**: no `Ellipse`, `StrokeStyle`, `strokeBorder`, arcs/curves in `Path`, shape transforms,
   `Canvas`; `stroke`/`border`/`tint` take only `Color`; `clipShape` takes only three concrete shapes.
7. **Animation semantics**: `.transition` is a no-op, springs are ease-outs, no `matchedGeometryEffect`,
   phase/keyframe animators, or completion callbacks.
8. **Scenes**: `WindowGroup` only; no `Settings`/`Window`/`DocumentGroup`/`MenuBarExtra`, no `.commands`,
   `.defaultSize` or other scene modifiers.

Some API that exists is accepted but does nothing, or does less than its signature says (section 5): `.onDelete`,
`.transition`, `.allowsHitTesting`, `.contentShape` (non-rectangular), `.toolbarBackground`, `.submitLabel`,
`.formStyle`, `.accessibilityAddTraits`, `.ignoresSafeArea`'s regions/edges, the `searchable` placement, gesture
masks, `GeometryProxy.frame(in:)` (always at the origin), springs.

## 2. Top P1 gaps

Ranked by how often typical apps hit them. "Tutorials" means Apple's SwiftUI tutorials (Landmarks,
Scrumdinger); "Skip" means SkipUI (a SwiftUI-on-Compose reimplementation) lists it as supported, i.e. its users
asked for it; "a/o" are call counts in apps written on Isomer / older native SwiftUI code (section 7). The apps
were written against Isomer, so their counts understate missing API; where they work around a gap it is noted.

1. **Value-based navigation.** `NavigationStack(path:root:)`, `NavigationPath`, `NavigationLink(value:label:)` / `NavigationLink(_:value:)`, `.navigationDestination(for:destination:)`, `.navigationDestination(isPresented:destination:)`, `.navigationDestination(item:destination:)`. Apple's navigation model since iOS 16 (programmatic push/pop, deep links, state restoration); agent_ui uses `navigationDestination` on its native path; Skip: full.
2. **Item-driven and dismiss-aware presentations.** `.sheet(item:onDismiss:content:)`, the `onDismiss:` argument of `.sheet(isPresented:)` and `.fullScreenCover`, `.fullScreenCover(item:)`, `.alert(_:isPresented:presenting:actions:message:)`, `.confirmationDialog(_:isPresented:titleVisibility:presenting:actions:)`. `sheet` is used 32/4 times; the item form is the standard "edit this row" pattern.
3. **`SecureField`.** Password entry. Visor's `PasswordField` falls back to a plain `TextField` where it is missing (visor_ui/Sources/PasswordField.swift); Skip: full.
4. **Bindings to collections.** `ForEach($items) { $item in ... }`, `List($items)`, `ForEach(_:editActions:content:)`, `List(_:editActions:rowContent:)`: `Binding` is not a `RandomAccessCollection` in Isomer and `ForEach`/`List` take no `Binding<C>`. Scrumdinger is built on this pattern.
5. **List editing.** `.onDelete(perform:)` exists but is never called (shared/swift_ui_core/ForEach.swift:68); `.onMove(perform:)`, `EditButton`, `EditMode` / `\.editMode`, `.deleteDisabled`, `.moveDisabled`, and the collection helpers the handlers call (`remove(atOffsets:)`, `move(fromOffsets:toOffset:)`) are missing. Landmarks and Scrumdinger both edit lists; Skip: full for onDelete/onMove.
6. **Style protocols.** `ButtonStyle` (+ `ButtonStyleConfiguration`), `PrimitiveButtonStyle`, `LabelStyle`, `ToggleStyle` and `.toggleStyle(_:)`, `ProgressViewStyle` and `.progressViewStyle(_:)`, `TextFieldStyle`, and the instance spellings `PlainButtonStyle()` (a/o 0/6), `PlainListStyle()` (0/4). Isomer's `buttonStyle`/`listStyle`/`labelStyle`/`textFieldStyle` take fixed option structs, so `.buttonStyle(.bordered)` compiles but any custom style does not. Scrumdinger defines a custom `LabelStyle` and `ProgressViewStyle`.
7. **Gestures beyond tap and drag.** `TapGesture`, `LongPressGesture`, `.onLongPressGesture(minimumDuration:maximumDistance:perform:onPressingChanged:)`, `@GestureState` with `Gesture.updating(_:body:)`, `.simultaneousGesture(_:including:)`, `.highPriorityGesture(_:including:)`, `Gesture.onChanged/onEnded/sequenced/exclusively/map` for any gesture. Skip: high for `TapGesture`, `LongPressGesture`, `onLongPressGesture`, `simultaneousGesture`.
8. **Formatted text.** `Text(_:format:)`, `Text(_:style:)` with `Text.DateStyle`, interpolation `"\(value, format: ...)"` and `"\(value, specifier: "%.1f")"`, `TextField(_:value:format:prompt:)`, `LabeledContent(_:value:format:)`. Numbers, dates and currency appear in nearly every app; Scrumdinger uses `Text(date, style: .date)`.
9. **`Text(AttributedString)`.** Attributed/markdown text built at run time (`AttributedString(markdown:)`). Isomer renders inline markdown of literal keys only; agent_ui's portable path shows such text unstyled (agent_ui/Sources/AgentUI/MarkdownText.swift).
10. **Text and font modifiers on any view; custom fonts.** `.fontWeight`, `.italic`, `.monospaced`, `.underline`, `.strikethrough` exist only on `Text` (so not on a `Label`, `Button` or container); `.fontDesign`, `.kerning`, `.tracking`, `.monospacedDigit`, `.minimumScaleFactor`, `.allowsTightening`, `.baselineOffset` are missing; `Font.custom(_:size:)`, `Font.custom(_:size:relativeTo:)`, `Font.system(_:design:weight:)`, `Font.italic()`, `Font.monospacedDigit()` and `Font.TextStyle` are missing. Skip: full for italic, monospaced, tracking, minimumScaleFactor.
11. **Environment values.** Missing: `locale`, `timeZone`, `calendar`, `openURL` (+ `OpenURLAction`), `isPresented`, `isSearching`, `dismissSearch`, `editMode`, `layoutDirection`, `dynamicTypeSize`, `accessibilityReduceMotion`, and the `@Entry` macro for custom keys. Several (font, lineLimit, tint) are stored internally but not public.
12. **`matchedGeometryEffect` and `@Namespace`; real transitions.** Hero animations need both; `.transition(_:)` is accepted and ignored (Modifiers.swift:868), `withAnimation(_:completionCriteria:_:completion:)` (completion callbacks) is missing.
13. **Shape strokes and basic shapes.** `Ellipse`, `StrokeStyle`, `Shape.stroke(_:style:)` / `stroke(style:)` / `stroke(lineWidth:)`, `InsettableShape.strokeBorder(...)`, `Shape.rotation(_:anchor:)`; `stroke` takes only a `Color`; `clipShape` accepts only `RoundedRectangle`, `Circle`, `Capsule`. Scrumdinger uses `strokeBorder` and `rotation`.
14. **Path construction.** `Path.addArc(center:radius:startAngle:endAngle:clockwise:)`, `addQuadCurve(to:control:)`, `addCurve(to:control1:control2:)`. Landmarks draws its badge with these; Scrumdinger its speaker arcs.
15. **Gradients and styles as `ShapeStyle` values.** `.linearGradient(colors:startPoint:endPoint:)`, `.radialGradient(...)` statics, `Color.gradient`, `.tint` as a style; `.foregroundStyle`/`.tint`/`.border` with gradients or hierarchical styles beyond Color.
16. **Layout essentials.** `.zIndex(_:)`, `.layoutPriority(_:)`, `.offset(_ offset: CGSize)`, `.scaledToFit()`/`.scaledToFill()` on any view (Isomer: `Image` only), `ViewThatFits`, `.coordinateSpace(_:)`; `GeometryProxy.frame(in:)` returns a frame at the origin whatever the space (Components.swift:86).
17. **Preferences.** `PreferenceKey`, `.preference(key:value:)`, `.onPreferenceChange(_:perform:)`: the standard child-to-parent channel (and how views report measured sizes). Skip: full.
18. **Visual effects and hit testing.** `.blur(radius:)`, `.mask(alignment:_:)` (and the older `.mask(_:)`), anchors on `.scaleEffect(_:anchor:)` / `.rotationEffect(_:anchor:)`, `.scaleEffect(x:y:)`; `.allowsHitTesting(false)` is a no-op (Modifiers.swift:861), so an overlay marked with it is not made transparent to taps.
19. **`.onReceive(_:perform:)`.** Combine publishers (`Timer.publish`, NotificationCenter). Visor guards its use; a/o 2/4; Skip: full.
20. **Toolbar composition and bar visibility.** `ToolbarContent` / `@ToolbarContentBuilder` (toolbar items factored into properties), `.toolbarVisibility(_:for:)` (hide a tab or navigation bar), `.navigationBarBackButtonHidden(_:)`, `.badge(_:)` (tab and row badges); `.toolbarBackground(_:for:)` is a no-op and has no `ShapeStyle` form.
21. **Control initializers.** `DatePicker` takes only `(_:selection:)`: no `displayedComponents:`, `in:` range, or label closure (Landmarks' profile editor uses all three); `Picker(selection:content:label:)`, `Slider(value:in:step:label:onEditingChanged:)`, `Stepper(value:in:step:label:)`, `Toggle(_:systemImage:isOn:)`, `Menu(_:systemImage:content:)`, `ProgressView(value:total:label:)`; `Slider` is `Double`-only.
22. **`AsyncImage` phases.** `AsyncImage(url:scale:transaction:content:)` with `AsyncImagePhase` (`.empty`/`.success`/`.failure`) for loading and error states; Isomer has only the content/placeholder form.
23. **Image rendering options.** `Image.renderingMode(_:)` (`.template`/`.original`), `.imageScale(_:)` and `Image.Scale`, `.symbolRenderingMode(_:)`, the `bundle:` argument of `Image(_:bundle:)`.
24. **Property-wrapper forms.** `@State var x: T?` with no initial value (`State.init()` for optionals), `@ScaledMetric`, `@SceneStorage`, `Binding.animation(_:)`.
25. **Search plumbing.** `.onSubmit(of: .search)`, `\.isSearching`, `\.dismissSearch`; `.searchable`'s `placement` is ignored (Components.swift:624).
26. **Desktop and web input.** `.keyboardShortcut(_:modifiers:)` (a/o 4/0), `.onHover(perform:)`, `.help(_:)`, `.focusable(_:)`: Isomer ships on web, Electron and desktop hosts, where these are expected.
27. **Scroll and list chrome.** `.scrollIndicators(_:axes:)`, `.scrollContentBackground(_:)` (the usual way to restyle a `List`/`Form` background). Skip: full for `scrollContentBackground`.
28. **`.textContentType(_:)`.** Autofill for usernames, passwords and one-time codes on sign-in forms (Visor's password field). Skip: high.
29. **Sheet sizes.** `PresentationDetent.fraction(_:)`, `.height(_:)`, `.custom(_:)`, and `presentationDetents(_:selection:)`; only `.medium`/`.large` reach the host (Presentations.swift:146).
30. **Scenes beyond one `WindowGroup` (desktop).** Isomer's `Scene` has no `body`, so no `SceneBuilder` composition, `Settings`, `Window`, `DocumentGroup`, `MenuBarExtra`, and none of the 33 scene modifiers (`.commands`, `.defaultSize`, `.onChange`, `.environment`, `.windowStyle`). Landmarks' macOS chapter uses `Settings` and `.commands` with `CommandMenu`. (Section 3 files most of these as P2/P3 by its platform rule; they are P1 for Isomer's desktop hosts.)

## 4. Present by name, narrower by type

The label comparison counts these as present, but the argument types Isomer accepts are narrower than
SwiftUI's, so ordinary call sites still fail to compile (found by normalizing parameter types and checked by hand).

- **`ForEach(_:content:)`, `ForEach(_:id:content:)`, `List(_:rowContent:)`:** no `Binding<C>` data (`ForEach($items) { $item in }`); `Binding` has no collection conformance (shared/swift_ui_core/ForEach.swift:27-44).
- **`Text(_:)`:** no `AttributedString`, `Date` range (`ClosedRange<Date>`) or `DateInterval` overloads.
- **`stroke(_:lineWidth:)`, `border(_:width:)`, `tint(_:)`:** take `Color` only (Shapes.swift:40, Modifiers.swift:490, Modifiers.swift:345); SwiftUI takes any `ShapeStyle` (gradients, `.tint`, `.secondary`).
- **`buttonStyle(_:)`, `listStyle(_:)`, `textFieldStyle(_:)`, `labelStyle(_:)`:** take Isomer option structs; `PlainButtonStyle()`, `.buttonStyle(MyStyle())` and every custom style fail.
- **`clipShape(_:)`:** three overloads (`RoundedRectangle`, `Circle`, `Capsule`), Modifiers.swift:461-473; no generic `Shape` (`Rectangle`/`.rect`, `Ellipse`, `UnevenRoundedRectangle`, custom paths); `.rect(cornerRadius:)` works.
- **`animation(_:value:)`:** requires `Hashable` values (Animation.swift:224); SwiftUI requires `Equatable`.
- **`safeAreaInset(edge:alignment:spacing:content:)` / `safeAreaBar`:** `VerticalEdge` only; the `HorizontalEdge` overload (leading/trailing insets) is missing, and `alignment` is ignored.
- **`lineLimit(_:)`:** no `PartialRangeFrom`/`PartialRangeThrough` forms (`.lineLimit(3...)`).
- **`Slider(value:in:)`, `Stepper`:** `Binding<Double>`/`Binding<Int>` only (SwiftUI: any `BinaryFloatingPoint`/`Strideable`), so `Float`/`CGFloat` bindings fail.
- **`List(selection:content:)`:** single selection only; no `Binding<Set<ID>>` multi-selection.
- **`navigationTitle(_:)`:** `String`/`Text`; no `Binding<String>` (editable, renamable titles).
- **`toolbarBackground(_:for:)`:** `Visibility` only, and a no-op; no `ShapeStyle` overload (`.toolbarBackground(.blue, for: .navigationBar)`).
- **`transition(_:)`:** `AnyTransition` only (no `some Transition`), and a no-op.
- **`searchable(text:placement:prompt:)`:** `prompt` is a `String` (SwiftUI: `Text?`/`LocalizedStringKey`).
- **`dropDestination(for:action:isTargeted:)`, `PhotosPickerItem.loadTransferable(type:)`:** deliver only `URL` or `Data` (files), whatever `Transferable` type is asked for (Pickers.swift:86, :209).
- **Controls' titles (`Button`, `Toggle`, `TextField`, `Picker`, `Menu`, ...):** `String` only; a `Text` title or a `Substring` does not compile (SwiftUI: `LocalizedStringKey`, `some StringProtocol`, `Text`).

## 7. Method, scope and limitations

1. **Apple's interface.** `tools/swiftui_audit/swiftdecl.py` reads `.swiftinterface` text: it strips comments and
   string contents, keeps every `#if` branch, tracks braces to find type/extension bodies (skipping function and
   accessor bodies), splits declaration headers, and records kind, name, argument labels (from the parameter
   clause; defaulted and closure parameters noted), generic constraints, the enclosing type/extension, and
   `@available` attributes inherited from the enclosing declarations. Module selectors (`SwiftUICore::View`,
   `SwiftUI.View`, `Swift.Bool`) are stripped. Inputs: SwiftUI and SwiftUICore, `arm64e-apple-ios` from the
   iPhoneOS SDK and `arm64e-apple-macos` from the MacOSX SDK (Xcode 27.0). A record counts for a platform unless
   that platform (or `*`) says `unavailable`/`obsoleted`; records are then merged across platform and module by
   (kind, qualified name, labels). Overloads that differ only in argument types merge into one signature.
2. **Isomer.** The same parser over the `SwiftUI` module's sources: `shared/swift_ui_core/*.swift`,
   `shared/renderers/*.swift`, `wasm/libraries/swift_ui/{WasmHost,WebBridge}.swift`,
   `android/libraries/swift_ui/{AndroidBridge,AndroidHost}.swift` (public/open declarations, members of
   `public extension`s, protocol requirements, enum cases; members of non-public types excluded). `shared/swift_ui_extensions`,
   `shared/platform_services` and the two `IsomerBridge.swift` files are separate modules and are not counted.
   Declarations marked `@available(*, unavailable)` count as absent.
3. **Matching** (`compare.py`). Types by qualified name. Members by container and base name; a SwiftUI signature is
   *present* if some Isomer overload can be called with SwiftUI's full label list (Isomer may have extra defaulted
   parameters; the first of a trailing run of closures may be unlabeled), *partial* if only a shorter call form
   works (a defaulted SwiftUI argument Isomer lacks), else *missing*. View modifiers SwiftUI declares on `View` that
   Isomer declares only on `Text`/`Image`/`Shape` count as partial. Static members of
   `extension ShapeStyle where Self == X` also match members of `X`; SwiftUI style protocols also match Isomer's
   `*StyleOption` structs. Enum cases and static properties match each other by name.
4. **Priorities** (`classify.py`). P1 from a curated list grounded in Apple's tutorials, SkipUI's support table
   (skip-ui's README.md, 220 entries) and usage; any whole-missing API used 3+ times in either
   corpus is P1. Secondary overloads of P1 modifiers (`isEnabled:`, `name:`, `fillStyle:`, token search, ...) are P2.
   P3: macOS- or iOS-only API, API introduced in the 26/27 SDKs, accessibility rotors, window/document/Touch Bar
   API, GraphicsContext, Table, keyframes, shaders and similar. Everything else P2.
5. **Usage** (`usage.py`). Regex counts (`.name(` for modifiers, the type name, `\.key` for environment values) over
   .swift files that `import SwiftUI`, comments and strings stripped, vendored/build directories excluded:
   "apps" = apps written on Isomer (visor, agent_ui, visor_isomer, isomer's examples and others, about 250 files);
   "old" = older native SwiftUI apps, examples and forks (179 files). Counts are approximate (name collisions).
6. **OpenSwiftUI** (OpenSwiftUI's `Sources/{OpenSwiftUI,OpenSwiftUICore}`) parsed the same way for the
   `OSUI` column (public declarations only; its availability macros are ignored).
7. **No-ops** (`noops.py`): public functions whose body is empty, returns `self`, or never reads a parameter,
   plus a read of comments like "accepted for source compatibility"; each listed item was checked by hand.

Skipped categories (declarations, both platforms merged):

- Protocol-conformance witnesses (==, hash, Codable, Collection, ...): 1446
- AppKit/UIKit hosting & interop (NS*/UI* types and extensions): 300
- Builder plumbing / extensions of Swift & CoreGraphics types: 233
- Result/plumbing types users never name (Tuple*, LimitedAvailability*, Default*Label, Empty*Content, ...): 196
- Immersive / spatial / compositor (visionOS family): 161
- Core Data integration: 61
- Xcode Previews: 34
- Widgets / control widgets / Live Activities / Watch: 28
- Platform-exclusive modifiers (watch/tv/vision/widgets/previews): 11
- Per-platform records marked unavailable on that platform: 2298 (an item available on the other platform is kept; watchOS/tvOS/visionOS-only API drops out here)
- Hard-deprecated: 27

Limitations:

- Names and labels, not types: an overload Isomer has with narrower argument types counts as present (section 4
  lists the ones found). Conversely a SwiftUI overload set that differs only by type collapses into one signature.
- Presence is not behaviour: section 5 lists what was seen to be inert, but no renderer was run.
- Priorities are judgement. The app corpora are small and the Isomer-era apps avoid what Isomer lacks; the older
  corpus predates most iOS 16+ API.
- Not covered: the cross-import overlays (`_MapKit_SwiftUI`, `_AVKit_SwiftUI`, `_PhotosUI_SwiftUI`,
  `_StoreKit_SwiftUI`, `_WebKit_SwiftUI`, `_SwiftData_SwiftUI`, ...), which Isomer partly reimplements (`Map`,
  `VideoPlayer`, `photosPicker`, `WebView` in SwiftUIExtensions); Charts; Observation, Combine
  (`ObservableObject`/`Published` are in Isomer's module), Foundation and CoreTransferable types.
- Raw data: `/tmp/swiftui_audit/results.json` (every SwiftUI item with its Isomer/OpenSwiftUI status),
  `/tmp/swiftui_audit/gaps_full.tsv` (every gap, including members of missing types, with signatures, priority,
  area, platforms, availability and usage). Rerun with `python3 extract_all.py && python3 compare.py &&
  python3 usage.py && python3 noops.py && python3 report.py` in that directory.
